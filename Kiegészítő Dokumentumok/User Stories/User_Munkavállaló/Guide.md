# Guide

**Requirements:** K15, L6
**Feature file:** [`NightlifeWorker/NightlifeWorkerTests/Features/Guide.feature`](../../../NightlifeWorker/NightlifeWorkerTests/Features/Guide.feature)

## User Story
As a worker
I want a guide that shows what the app can do, behind its own button
So that I can learn to use it on my own

## Acceptance criteria
The acceptance criteria are the scenarios of the feature file above (single source of truth):

* The guide has its own button on the home screen and is also in the settings
* It has a section for every feature I can use, in the order of the home screen
* Features the administrator turned off are not described
* The administrator can turn the guide itself off (L6)
