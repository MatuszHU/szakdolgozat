# Venue Guide

**Requirements:** M5, L7
**Feature file:** [`Nightlife/NightlifeTests/Features/VenueGuide.feature`](../../../Nightlife/NightlifeTests/Features/VenueGuide.feature)

## User Story
As a guest
I want to see the floor plan of the venue with the places that matter to me
So that I can find the bar, the toilets, the stage, the cloakroom and the exits

## Acceptance criteria
The acceptance criteria are the scenarios of the feature file above (single source of truth):

* The map opens on the ground floor
* The guest sees bars, toilets, stages, cloakrooms, entrances and exits
* Staff-only places (custom points of interest) and the staff zones are hidden
* The guest can switch between floors
* Without a floor plan the guest is told that the map is not available yet
