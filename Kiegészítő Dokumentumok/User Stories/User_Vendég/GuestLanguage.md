# Guest Language

**Requirements:** M10, M8
**Feature file:** [`Nightlife/NightlifeTests/Features/GuestLanguage.feature`](../../../Nightlife/NightlifeTests/Features/GuestLanguage.feature)

## User Story
As a guest
I want to choose the language of the app
So that I can use it even if I do not speak Hungarian

## Acceptance criteria
The acceptance criteria are the scenarios of the feature file above (single source of truth):

* By default the app follows the language of the phone
* Hungarian, English, German, European Portuguese, Slovak, Romanian, Croatian and Ukrainian can be chosen in the settings (M8)
* The choice is kept after restarting the app
* Every text of the app has a version in all eight languages
